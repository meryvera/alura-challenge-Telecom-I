# TelecomX_LATAM - Análisis de Churn

Este proyecto realiza un proceso ETL y un análisis exploratorio sobre los datos de clientes de Telecom X.

## Instalación y Dependencias
- Python 3.x
- Pandas, Seaborn, Matplotlib, Requests

## Cómo ejecutar
1. Abre el archivo `TelecomX_LATAM_done.ipynb` en Google Colab.
2. Ejecuta las celdas en orden (Extracción -> Transformación -> Análisis).
